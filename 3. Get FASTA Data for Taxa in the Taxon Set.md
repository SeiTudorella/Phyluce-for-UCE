Get FASTA Data for Taxa in the Taxon Set
---

This script will create a monolithic FASTA file (all data for all organisms) named ```all-taxa-incomplete.fasta```.

```
# /bin/sh 
# ----------------Parameters---------------------- # 
#$ -S /bin/sh 
#$ -q sThC.q 
#$ -l mres=2G,h_data=2G,h_vmem=2G 
#$ -cwd 
#$ -j y 
#$ -N getfasta 
#$ -o getfasta.log 
#$ -m bea 
#$ -M Username@si.edu 
# 
# ----------------Modules------------------------- # 
module load bioinformatics/phyluce/1.7.3 
# 
# ----------------Your Commands------------------- # 
# 
echo + `date` job $JOB_NAME started in $QUEUE with jobID=$JOB_ID on $HOSTNAME 
# 
 
phyluce_assembly_get_fastas_from_match_counts   
--contigs /path/to/contigs 
# this must go to a directory, not a file. A forward slash is not needed at the end  
--locus-db /path/to/probe.matches.sqlite   
--match-count-output all-taxa-incomplete.conf   
--output all-taxa-incomplete.fasta   
--incomplete-matrix all-taxa-incomplete.incomplete   
--log-path log  
# 
echo = `date` job $JOB_NAME done
```
