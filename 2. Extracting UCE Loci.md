Extracting UCE Loci
---
In the working directory, create a file named “taxon-set.conf”.

Open taxon-set.conf with ```nano``` and list all the taxon names like this:
```
[all]
sample1
sample2
sample3
...
```
You will create an initial list of loci for each taxon using the command```phyluce_assembly_get_match_counts```.

Next, create an output directory with ```mkdir -p taxon-sets/all```. A new file named ```all-taxa-incomplete.conf```will be saved here.

Again, the command must be in one line.

```
# /bin/sh 
# ----------------Parameters---------------------- # 
#$ -S /bin/sh 
#$ -pe mthread 2 
#$ -q sThC.q 
#$ -l mres=4G,h_data=2G,h_vmem=2G 
#$ -cwd 
#$ -j y 
#$ -N matchcounts 
#$ -o matchcounts.log 
#$ -m bea 
#$ -M seim@si.edu 
# 
# ----------------Modules------------------------- # 
module load bioinformatics/phyluce/1.7.3 
# 
# ----------------Your Commands------------------- # 
# 
echo + `date` job $JOB_NAME started in $QUEUE with jobID=$JOB_ID on $HOSTNAME 
# 
phyluce_assembly_get_match_counts   
--locus-db /working/directory/probe.matches.sqlite 
--taxon-list-config taxon-set.conf  
    	--taxon-group 'all'   
--incomplete-matrix 
--output taxon-sets/all/all-taxa-incomplete.conf  
# 
echo = `date` job $JOB_NAME done 
```
